# SableOS on the Zinwa Q25: every app's keys

This is the full key list for every Sable app, taken from each app's key code. The [User Guide](USER_GUIDE.md) gives the short version in its Apps table.

**Before you start.**

- **Plain letters are commands.** A letter only does something when no text field has the cursor. In a search or text field, letters type, and Esc (or Back) leaves the field.
- **No Ctrl, no Esc.** The Q25 has Alt, Shift and Sym but no Ctrl or Esc key. Where a list below says Ctrl, that chord only works on a keyboard that has Ctrl. On the Q25, Back does what Esc does.
- **Holding a key.** Holding a key repeats only moving and paging. A held D never deletes twice.
- **Trackpad.** The trackpad sends the arrow keys, and a click is Enter. In the Browser it drives a pointer instead (M switches the pointer off).

## Keys that work everywhere

| Key | Does |
| --- | --- |
| Menu (the BlackBerry key) | The screen's full menu, with Close last |
| T / B | Top / bottom of a list (not in a text field) |
| Space / Shift+Space | Page down / up |
| N / P | Next / previous item, where the app has no other use for them |
| Back at an app's first screen | Shows Active Frames and leaves the app running |
| Recents key | Active Frames. Hold it for the Hub over the app you are in |
| Alt+BlackBerry key | The system menu: Hub, the app's menu, Close, Switch Application, Notifications, Quick Settings |
| Alt+Space | Command (search and quick actions) from any app. On the lock screen, the emergency dialer |
| Alt+Shift+R | Next display size for the app in front (App Compatibility) |
| Alt+Shift+P | Privacy Screen on or off |
| Alt+Shift+V (held) | Clipboard history, when it is on in Keyboard settings |

## Games and Sable Games Console

The keys for each game are in [Games](USER_GUIDE.md#games) and [Sable Games Console](USER_GUIDE.md#sable-games-console) in the User Guide. In short:

- **Every game:** arrows or the trackpad move, Space or Enter is the main action, N starts a new game (in Words, Enter starts the next round), P pauses, U undoes where a game allows it.
- **Sudoku:** W E R S D F Z X C (or Alt+digits) enter 1 to 9, Del erases.
- **Minesweeper:** F or G flags.
- **Mahjong:** H shows a pair. **Solitaire:** A sends a card to its foundation, Del lets go.
- **Console library:** Left / Right change tab, Up / Down pick, Space or Enter plays, I details, A add games, S settings.
- **Console tilt games:** W A S D work like the arrows, Space sets level before a game, K plays with keys, Back or P pauses. In the pause menu: R resume, N new game, L level again, T tilt sensitivity, K keys, Q quit.
